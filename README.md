# BLIP design gallery

Every current screen of the BLIP Quiet Console, plus the mascot in all twenty states.

**Live gallery:** https://zayfe7.github.io/blip-design-gallery/

## Contents

- `index.html` - the gallery. Open it in a browser.
- `screens/` - 31 full-resolution PNGs: chat, streaming, approval, goals, automations, connections, files, artifacts, settings, dialogs, dark mode and phone screens.
- `mascot-keyframes.png` - all 20 mascot states, four sampled frames each (1320 x 4222).
- `mascot-animation-lab.html` - the animated lab with every frame, blink and transition.
- `manifest.json` - screen labels and viewport sizes.

## For Figma

Upload the `screens/` folder and `mascot-keyframes.png` as flat references. Figma cannot carry the canvas animation; use `mascot-animation-lab.html` to judge motion.

## Data

Captured 2026-10-31 from the Quiet Console fixture with neutral demo data. No keys, account data or personal email addresses are included.
