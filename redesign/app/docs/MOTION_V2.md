# Blip v2 — quietly curious

The simple rounded silhouette and two white eyes remain recognizable. The motion has been re-authored; the old 20 pose functions are not presented as unchanged.

The catalog contains 37 lifecycle states across rest, attention, work, waiting, outcome and recovery, preserving all original state IDs. It is extensible rather than claiming to enumerate every possible future backend event. Each state has an explicit meaning, motion note, loop/one-shot/hold behavior and canonical reduced-motion still time.

The body has a soft ink-like finish, subtle upper rim and grounded contact shadow at large sizes. Small instances omit ornament. No mouth, limbs, constant decorative orbit, fake heartbeat or repeated celebration loop is added.

Transitions use exact critically damped integration that retains velocity during interruptions. Body deformation and gaze amplitudes are bounded. Approval/queue/access/input settle patiently; failure is concerned and stable; cancellation neutral; completion uses happy eyes and one tiny relief nod. Loading and reconnection keep the face present. Speaking can use real supplied audio energy, not an invented waveform.

One shared requestAnimationFrame scheduler pauses offscreen/background canvases and caps DPR at 2. Pause freezes the current pose; reduced motion displays an intentional static expression. An animation finishing never proves a real tool or agent completed.

The immutable baseline ZIP retains the old renderer for reference. Historical v1 audits are not validation of v2; fresh results are recorded in the revision QA report.
